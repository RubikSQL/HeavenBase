# Current Reports

This folder contains evidence that remains useful for the checked-out source surface:

- generated capability and benchmark material;
- explicit estimates whose assumptions remain current;
- release/refactor summaries that still explain a maintained compatibility boundary.

Reports are evidence, not task queues or architecture authorities. Put accepted contracts in `docs/resources/architecture/` or `docs/resources/reference/`, put active follow-up in `docs/tasks.yaml`, and record concise completion evidence in `docs/DEVLOG.md`.

Remove a report when its assumptions, paths, or status no longer describe the current source and its durable conclusions already live in code, tests, architecture, or reference documentation.
